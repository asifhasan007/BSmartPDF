BSmartPDF: Intelligent Document Interaction
BSmartPDF is a full-stack application designed to revolutionize how users engage with their documents. It provides an intuitive chat interface allowing users to "talk" to their PDFs. The application combines a responsive Angular frontend with a powerful Python backend to deliver a seamless, interactive experience for complex document analysis. My primary role was leading the backend development to build a robust and scalable AI engine.

Key Features:

Interactive Chat Interface: A responsive and user-friendly frontend built with Angular and TypeScript for real-time interaction.

Natural Language Querying: Users can ask complex questions and receive context-aware answers extracted directly from their PDF documents.

Hybrid LLM Integration: The backend leverages both powerful cloud-based APIs (like ChatGPT) and local LLMs, offering flexibility and control over data processing.

Multi-Language Support: The system is designed for a global audience, with successful implementation of Bangla language support.

Tech Stack:

Frontend: Angular, TypeScript

Backend: Python, Flask, LangChain

Databases : PostgreSQL, Vector Databases

Deployment: Docker
